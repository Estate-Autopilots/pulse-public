# Chrome Web Store package

The release includes `Pulse-VERSION-chrome-web-store.zip` with the manifest at ZIP root, icons, scripts and shared companion code. It is the same reviewed extension as the unpacked download. It requests only the existing Pulse production host; optional work-context hosts remain optional.

Submit this ZIP in the owner's Chrome Web Store developer account. Supply the store privacy disclosures and the public privacy URL before publishing. There is no store listing or extension update URL yet. Until listing approval, Pip offers a ZIP download and explains how to replace the unpacked files and click Reload. Android-style sideloading and background replacement cannot update an unpacked extension.

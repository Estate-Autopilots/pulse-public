# Estate Autopilots logo (official)

Taken on 11 Oct 2026 from **EA BRANDING BRIEF.pdf** (marketing@estateautopilots.com, Drive, April 2026): the "Eâ"
monogram on the Estate Gold tile with the "estate autopilots" wordmark. The paths are the brief's own outlines
(PyMuPDF export with text as paths), not a redraw.

| File | Use |
| --- | --- |
| `ea-mark.svg` | The tile alone: Pulse's rail, small places |
| `ea-logo.svg` | Horizontal lock-up on light backgrounds |
| `ea-logo-on-dark.svg` | The same on dark backgrounds (white wordmark) |
| `ea-logo-mono.svg` | One colour (`currentColor`), no tile |
| `ea-logo-96.png` | Raster of the lock-up, 96 px tall, for e-mail |

Colours from the brief: Estate Gold `#fbc701`, Midnight Estate `#021f2d`, Stone Canvas `#e8e2db`, Soft Concrete
`#e9edf0`. In Pulse these are the EA organisation's logo (migration 0164, `pulse.org_brand`); any other organisation
uploads its own in Settings → Organisation.
